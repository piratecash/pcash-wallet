# Classes that something resolves by their original name at runtime. R8 must leave the
# name alone, so renaming or moving one here is a silent, release-only breakage: the
# build stays green and the failure surfaces as "class not found" or "field is null".
#
# verifyR8RulesQa / verifyR8RulesRelease fails when an entry is renamed or has vanished
# from mapping.txt. A vanished entry usually means the class moved — move it here too,
# and fix the keep rule that no longer covers it.
